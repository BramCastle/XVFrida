# Frida Paulina Perez Hernandez — Invitación de XV años

Sitio estático de una sola página. Para previsualizarlo, abre `index.html` en el navegador o sirve la carpeta con cualquier servidor estático.

## Datos editables

En `script.js`, edita `EVENT_CONFIG` para configurar:

- `eventDate`: fecha objetivo de la cuenta regresiva con formato `{ year, month, day }`.
- `audioSrc`: ruta local o URL autorizada de “Photograph — Ed Sheeran”. Si está vacío, el reproductor permanece deshabilitado.
- `whatsappNumber`: número con código de país; el script limpia automáticamente `+`, espacios y guiones.
- `whatsappMessage`: mensaje prellenado para confirmar asistencia.
